## 1. S1 — 2.77 s freeze at the first Savage Sweep (C)

is inside `World.spawn(0x40000CD6)` (`ics/world.py:987`).

**Mechanism (C, the server's readers run on the data, cold process).** `World.spawn` calls, for a class it has never
seen, `Data.unit_attack` / `Data.unit_stats` (`world.py:994-995`, to decide unit vs prop) and `Data.creation_type`

(`gamedata.py:984`) runs at server start for the configured encounters with the flow's classes only
(`ics/server.py _warm_up`, `flow_classes` = [] for PvP); champions' skill objects are never prepared.

**Census (C).** 78 entity classes are created by `SpawnEntity` in the 875 decoded scripts. Their stat blocks: most
